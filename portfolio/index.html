Used-Car Marketplace Search

Source Code

I built this when I was looking for a used car in Germany. It searches Kleinanzeigen and AutoScout24 with one set of criteria and merges everything into a single report I can check from my phone.

Highlights

  • Trust nothing: mileage and accident status are re-checked on every listing, since one site's filter silently does nothing
  • Accident detection: uses the site's structured damage field where it exists, otherwise reads the ad text and flags "not stated"
  • Deep details: gearbox, TÜV date and post date fetched once per ad from its own page

Engineering

  • Tracking across runs: remembers every ad, its first and last seen dates and price changes
  • Web viewer: mark ads as reviewed or shortlisted, and trigger a new search from the page
  • Pluggable sites: adding a marketplace means adding one module with a search() function
